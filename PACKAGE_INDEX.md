# Package contents

- `AGENTS.md`: mandatory agent behavior and scope-control rules.
- `README_AGENT_HANDOFF.md`: project overview and approved technical baseline.
- `DEVELOPMENT_PHASES.md`: phased implementation plan and acceptance criteria.
- `START_HERE_PROMPT.md`: first prompt to give the agent.
- `project_docs/`: six design documents.
- `reference_material/`: original requirement notes and supplied PDF examples.

Start with `START_HERE_PROMPT.md`. The agent must perform Phase 0 only and must not modify the project or environment until instructed.
